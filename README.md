# Workflow
- Для деплоя был реализован github экшнс, деплой происходит автоматически после мержа пулл реквеста
- При деплое прогоняются тесты, валидируются типы.
- Мерж пулл-реквеста, каждый пулл-реквест должен получить аппрув от нейросети.
- Задачи назначаются через Linear.
- Задачи полностью Fullstack, то есть разработчик должен реализовать и Frontend и Backend и тесты. Благодаря этому избегается проблема параллельных массивов.
- Деплой происходит на Linux, а не на FreeBSD (хотя мне FreeBSD нравится больше) только по той причине что линукс поддерживает контейнеры лучше.
